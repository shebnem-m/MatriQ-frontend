Reference

One source of truth for how MatriQ looks.

Copy the tokens below into your own pages instead of eyeballing colors from the mockup. Every hex value, font, and spacing rule here is exactly what the landing page uses — if your page uses these same tokens, it'll look like it belongs.

Typography

Three fonts, three jobs. Don't introduce a fourth.

Display — Space Grotesk headings, hero, prices

Source materials, verified.

Section headings use font-600

Body — Inter paragraphs, nav, buttons

Body copy stays in Inter at text-base or text-lg, ink at 70-80% opacity rather than a lighter gray — keeps warmth consistent with the paper background.

Mono — IBM Plex Mono specs, eyebrows, prices, labels

SS304 · Ø12mm · $0.92 / kg

Verified suppliers · Live specs

Google Fonts import — paste this in every page's <head>:

<link href="https://fonts.googleapis.com/css2?family=Space+Grotesk:wght@400;500;600;700&family=Inter:wght@400;500;600&family=IBM+Plex+Mono:wght@400;500;600&display=swap" rel="stylesheet">

A few hard rules

  • — Backgrounds are paper or paper2. Never pure white, never a gray-50 default.
  • — Corners are rounded-sm (2px), not rounded-lg/xl. Keep it sharp and industrial.
  • — Eyebrows (small uppercase labels above headings) are always font-mono, tracking-[0.18em], text-steel.
  • — Specs, prices, and codes are always font-mono — never Inter.
  • — Don't add a new accent color. If something needs emphasis, use rust — sparingly — or weight/size instead.

Drop-in Tailwind config

Paste this into your tailwind.config.js (or the CDN config block) so class names like bg-rust or font-display work identically across everyone's pages.

theme: {
  extend: {
    colors: {
      ink: '#1C1B19',
      paper: '#EDE8DF',
      paper2: '#E3DDD0',
      steel: '#4C6B77',
      rust: '#B5502A',
      stone: '#9C9689',
      chalk: '#FAF9F6',
    },
    fontFamily: {
      display: ['Space Grotesk', 'sans-serif'],
      body: ['Inter', 'sans-serif'],
      mono: ['IBM Plex Mono', 'monospace'],
    },
  },
}
